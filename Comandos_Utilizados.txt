######   Crear un proyecto MVC
Nos paramos en la carpeta que realizaremos le proyecto y ejecutamos

 dotnet new mvc


######## Prepara la migracion
 dotnet ef migrations add NombreMigracion


#########  Ejecuta la migracion a la DB
 dotnet ef database update



 ######### Para ejectuar la aplicacion
 dotnet run

 o tambien

dotnet watch run
